# Polska na żywo – kamery i radio 🇵🇱

Darmowe, legalne playlisty M3U z polskimi kamerami internetowymi i stacjami radiowymi.
Wszystkie linki prowadzą do publicznych streamów udostępnianych przez same stacje, gminy i serwisy z kamerami.

## Playlisty

| Plik | Zawartość | Liczba |
|---|---|---|
| `kamery.m3u` | Kamery live: góry, morze, jeziora, miasta i inne | 2992 |
| `radio.m3u` | Polskie stacje radiowe: RMF, Polskie Radio, Eurozet, ESKA, regionalne, lokalne | 915 |
| `wszystko.m3u` | Kamery i radio w jednej liście | 3907 |

## Jak używać

Skopiuj link do pliku w wersji „Raw” i wklej go w odtwarzaczu IPTV albo w VLC („Otwórz strumień sieciowy”):

```
https://raw.githubusercontent.com/TWOJA_NAZWA/polska-na-zywo/main/kamery.m3u
https://raw.githubusercontent.com/TWOJA_NAZWA/polska-na-zywo/main/radio.m3u
```

Pasujące aplikacje: VLC, TiviMate, IPTV Smarters, OTT Navigator, Kodi (PVR IPTV Simple Client).

## Telewizja

Darmowe polskie kanały TV są w osobnych, aktualizowanych projektach. Możesz dodać je w odtwarzaczu jako drugą playlistę:

- Free-TV: `https://raw.githubusercontent.com/Free-TV/IPTV/master/playlist.m3u8`
- iptv-org (Polska): `https://iptv-org.github.io/iptv/countries/pl.m3u`

## Zasady

- Tylko publiczne, darmowe źródła.
- Bez płatnych kanałów, VOD i treści pirackich.
- Bez prywatnych kamer: tylko kamery udostępnione celowo przez właścicieli.

Jeśli Twoja kamera lub stacja jest tu, a nie chcesz, żeby była, załóż zgłoszenie (Issue), a usunę ją.

## Uwagi

Streamy czasem zmieniają adresy, więc pojedyncze pozycje mogą nie działać. Kategorie kamer przydzielono automatycznie według nazw, więc zdarzają się pomyłki.
